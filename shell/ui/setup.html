DigUp Plus only reads files: it never changes, moves or uploads them. Nothing is indexed until you choose folders; they can be added later in Settings → Folders.

Search your code too?

DigUp Plus can find code by what it does: type “code:” in the search panel and say what you're looking for. Code gets an index of its own and shows up only when you search for code. Pick the folders that hold your code, or leave them all and turn it on later in Settings.

DigUp Plus reads what git keeps (not dependencies or build output). The time is reading it once; after that, only what changes is read again.
